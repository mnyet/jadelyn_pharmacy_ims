# 💊 Jadelyn Pharmacy IMS
🚧 **Status: Under Active Development** — Not yet ready for production use

- **IMS** stands for Internal Management System
- This is a personal project dedicated to create an Internal Management System for our family business.
- Simplifying inventory, sales, and reports required to comply with business standards.

## 🚀 Quick Overview
This system helps us track medicines, process sales, manage prescriptions, and generate daily reports - all in one place.

## 🔑 Core Features
- [x] Role Based Access/Management
- [x] Inventory Management
- [x] Management Page (For Generic Names, Brand Names, and Product Types)
- [ ] Point of Sale
- [ ] Inventory Reports
- [ ] Sales Reports

## 🛠️ Tech Used
- This project was made under Codeigniter 4 and is currently utilizing DDEV.
- The project is also using a Monolithic structure as this is only a small project.
    ### Frontend:
    - Bootstrap 5
    - Select2
    - JQuery
    - Datatables
    - SweetAlert2
    ### Backend:
    - Hermawan/DataTables
    - MySQL 8.0.11 (Uses TiDB Cloud Serverless)
